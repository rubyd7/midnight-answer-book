# 此页有回音

**把犹豫写成问题，把偶然翻成灵感。**

有些问题，在心里绕了很久。
给自己一点安静，翻开这本书，让一句偶然遇见的话，成为下一步的灵感。

一本藏着 **257 句回音** 的互动答案之书，等你亲手停在属于此刻的一页。

## ✦ 翻开这一页

[进入答案之书](https://rubyd7.github.io/midnight-answer-book/)

1. 写下问题，或在心里默念。
2. 轻点书本打开封面，再点一下，让书页流转。
3. 在想停下的那一刻，轻点书本，读一读这一页。
4. 再点一下继续翻页，或合上书，留给下一个问题。

也可以用 Tab 聚焦书本，再按 Enter 或空格操作。

> 书里的答案只有 257 种，属于你人生的答案，却有无限种。
> 把它当作一份灵感，把选择留给自己。

## ✦ 一点小小的仪式感

- 暗色书桌、烫金封面与纸张纹理。
- 立体翻页动画，答案在暂停时浮现。
- 适配手机与电脑，支持键盘操作和减少动态效果偏好。
- 问题留在当前页面；现有代码不上传问题，也不调用 AI 接口。

## ✦ 在自己的电脑上打开

下载仓库后，直接用浏览器打开 `dist/index.html`。无需安装依赖或构建。

| 文件 | 内容 |
| --- | --- |
| `dist/index.html` | 页面结构、样式和书本外观 |
| `dist/app.js` | 打开、翻页、暂停与重新提问 |
| `dist/answers.js` | 257 条答案 |
| `.openai/hosting.json` | 原始 Sites 部署配置 |

部署到静态托管服务时，发布目录为 `dist`。本仓库已配置 GitHub Pages：更新 `main` 分支中的网站文件后，GitHub Actions 会自动重新部署。
